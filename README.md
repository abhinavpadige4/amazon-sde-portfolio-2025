# Amazon SDE Portfolio 2025

Portfolio website for an Amazon Software Development Engineer showcasing AWS, distributed systems, and DSA expertise. Built with Next.js 14, TypeScript, and Tailwind CSS.

## Features

- Modern, responsive design
- AWS expertise showcase
- Distributed systems experience
- DSA and algorithm optimization focus
- Cloud-native development background
- Clean, professional interface

## Tech Stack

- **Framework:** Next.js 14
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Deployment:** Vercel

## Getting Started

```bash
npm install
npm run dev
```

## Deployment

This project is configured for automatic deployment to Vercel.
